⌨️ Тайп-марафон — игра для тренировки скорости печати

📌 Описание проекта

Тайп-марафон — это обучающая игра, разработанная на Python с использованием библиотеки Pygame.  
Игроку предлагается печатать слова как можно быстрее и точнее за ограниченное время.


🎯 Основные возможности

- 🟢 Несколько уровней сложности
- ⏱ Таймер
- 📊 Подсчет скорости (WPM)
- 🎯 Подсчет точности
- 🎮 Удобный интерфейс
- 🔤 Подсветка правильных и неправильных символов



🧠 Уровни сложности

| Уровень | Описание | Время |
|--------|--------|------|
| 1 | Новичок | 60 сек |
| 2 | Средний | 60 сек |
| 3 | Профи | 45 сек |
