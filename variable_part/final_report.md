 8. Финальный отчет о выполнении проекта

 8.1 Хронология выполнения работ

 Этап 1 — Постановка задачи
- Определена цель проекта: разработка игры для тренировки скорости печати
- Выбран язык программирования: Python
- Выбрана библиотека: Pygame
- Сформированы основные требования:
  - наличие уровней сложности
  - ограничение по времени
  - подсчет скорости и точности



 Этап 2 — Изучение технологий
- Изучена библиотека Pygame:
  - создание окна
  - работа с событиями
  - отрисовка графики
- Освоена обработка клавиатурного ввода
- Изучена работа с таймером (модуль time)



 Этап 3 — Проектирование программы
- Определена структура проекта
- Выделены основные состояния игры:
  - menu (меню)
  - playing (игра)
  - game_over (конец игры)
- Разработана система уровней сложности
- Спроектирована логика подсчета статистики



 Этап 4 — Реализация базовой структуры
- Создано окно приложения
- Реализован главный игровой цикл
- Настроена обработка событий (pygame.event)



 Этап 5 — Реализация игровой логики
- Добавлена генерация случайных слов (random.choice)
- Реализован ввод текста пользователем
- Добавлена проверка правильности ввода
- Реализована логика смены слов



 Этап 6 — Реализация статистики
- Добавлен подсчет скорости печати (WPM)
- Реализован подсчет точности (%)
- Добавлен таймер с ограничением времени



 Этап 7 — Разработка интерфейса
- Реализовано меню выбора уровня
- Добавлен игровой экран:
  - текущее слово
  - поле ввода
  - таймер
  - прогресс-бар
- Добавлен экран завершения игры



 Этап 8 — Тестирование и отладка
- Проверена корректность ввода
- Проверена работа таймера
- Проверены формулы расчета статистики
- Исправлены ошибки и баги



 Этап 9 — Финализация проекта
- Оптимизирован код
- Улучшен внешний вид интерфейса
- Подготовлена документация
- Оформлен отчет
