⌨️ Тайп-марафон
Игра для тренировки скорости печати

Проверь свою скорость набора текста на русском языке. Три уровня сложности, таймер, подсчёт WPM и точности.

Начать игру

📖 О проекте

Тайп-марафон — это обучающая игра, разработанная на Python с использованием библиотеки Pygame. Игроку предлагается печатать появляющиеся слова на экране до истечения таймера. Чем быстрее и точнее ввод, тем выше результат.

🎯 Основные возможности

  • 🟢 Три уровня сложности (с разными словарями)
  • ⏱ Обратный таймер с визуальным прогресс-баром
  • 📊 Расчёт скорости печати (WPM — слов в минуту)
  • 🎯 Подсчёт точности ввода (процент правильных символов)
  • 🎮 Удобный интерфейс с поддержкой клавиатуры
  • 🔤 Подсветка правильных (зелёный) и ошибочных (красный) символов

🎮 Как играть

↑ / ↓ — выбор уровня в меню Enter — старт / подтвердить слово Backspace — удалить символ Esc — выход в меню (во время игры) R — переиграть (на экране Game Over)

Печатайте слово, которое видите на экране. Каждая буква подсвечивается зелёным, если она правильная, или красным — если ошиблись. Нажмите Enter, чтобы перейти к следующему слову. По истечении времени увидите вашу скорость (WPM) и точность.

🛠 Установка и запуск

Требования: Python 3.7 или новее, библиотека Pygame.

  1. Склонируйте репозиторий или скачайте файл main.py: 
    git clone https://github.com/ваш_логин/type-marathon.git
cd type-marathon
  2. Установите Pygame: 
    pip install pygame
  3. Запустите игру: 
    python main.py

🧠 Как это работает (пример кода)

Основная логика: слова из уровней, посимвольное сравнение и подсчёт WPM.

def get_wpm():
    elapsed = max(time.time() - start_time, 1)
    words_typed = correct_chars / 5
    return round(words_typed * 60 / elapsed)

def reset_game():
    global current_word, input_text, start_time, correct_chars, total_chars
    current_word = random.choice(level_data["words"])
    input_text = ""
    start_time = time.time()
    correct_chars = 0
    total_chars = 0

Полный исходный код игры доступен в репозитории (файл main.py).

📊 Метрики

  • WPM (слов в минуту): (количество правильно набранных символов / 5) * 60 / прошедшие секунды.
  • Точность: (правильные символы / общее число введённых символов) * 100%.
