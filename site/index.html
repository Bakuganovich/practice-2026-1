Финатлон: финансовая олимпиада

Проект по дисциплине «Проектная деятельность» — создание информационного портала о Всероссийской олимпиаде по финансовой грамотности.

Узнать больше

Аннотация проекта

Цель проекта: разработать информационный веб-сайт, посвящённый Всероссийской олимпиаде школьников «Финантон» по финансовой грамотности. Сайт объединяет ключевые сведения об олимпиаде, этапах участия, полезных ресурсах и даёт возможность отслеживать прогресс подготовки команды.

Актуальность: финансовая грамотность становится обязательным навыком XXI века. Олимпиада «Финантон» ежегодно привлекает тысячи школьников, но многие испытывают дефицит структурированной информации. Наш проект закрывает эту потребность.

Целевая аудитория: школьники 8–11 классов, учителя экономики, родители, организаторы олимпиад.

Ожидаемые результаты: функциональный сайт с уникальным контентом, доступный в сети; повышение информированности об олимпиаде; методическая поддержка участников.
